# Clip Pocket 0.4.0

Клиппер для Windows/macOS, VST3 + AAX. Две большие ручки **Input Gain / Ceiling**, под ними **Style / Knee / Low Protect / Output Gain**. Справа сегментные вертикальные OUT и GR со шкалами и отдельными пиковыми значениями; нажатие на верхнее значение сбрасывает его. Нижние подписи и Delta удалены. Темы Solid Dark, Neon и Amber, blur при bypass и исходный дизайн Pocket сохранены.

| Контроль | Действие |
|---|---|
| Input Gain | −24…+36 dB до клиппинга. |
| Ceiling | −30…0 dB, порог клиппинга. По умолчанию 0.00 dB. |
| Style | Три фиксированных положения: 0% Clean, 50% Punchy, 100% Analog. |
| Knee | 0…100%, жёсткое → мягкое ограничение. По умолчанию 0% (жёстко). |
| Low Protect | Плавная защита перегруженной НЧ-составляющей около 100 Hz; по умолчанию 0%. |
| Output Gain | −24…+12 dB после основного алгоритма, перед финальным sample-ограничением. |
| Quality, в меню | 2x–64x, по умолчанию 16x. Отдельное 64x для offline render. |
| Bypass | Задержанный исходный сигнал. |

**Активная обработка не выдаёт обычные sample peaks выше 0 dBFS.** Финальная граница после Output Gain — `min(1, Ceiling_linear × OutputGain_linear)`. Например, Ceiling −6 dB и Output −3 dB дают предел −9 dBFS; положительный Output не может вывести активный тракт выше 0 dBFS. Bypass передаёт исходный сигнал, включая его исходные перегрузки.

Это не true-peak/ISP ограничитель: пики восстановленной непрерывной волны могут быть выше 0 dBTP. Финальная защита ограничивает сэмплы после реконструкции и может добавить гармоники/алиасинг при сильном срабатывании.

Clean — прямой oversampled clipping; Punchy — прежний Cancel с ограниченной компенсацией НЧ-искажений; Analog — плавная tanh-форма при увеличении Knee. При Knee = 0 Clean и Analog используют жёсткую кривую. Multiband, Fold и Orbit удалены.

Low Protect уменьшает клиппинг баса через плавное регулирование усиления. На НЧ-доминантных фрагментах приближается к лимитеру, на смешанном сигнале преимущественно защищает низкую полосу. Он может снижать уровень бочки и затрагивать одновременно звучащие инструменты; не выделяет отдельную дорожку.

Постоянная задержка — **768 сэмплов** (16 ms при 48 kHz), все качества и bypass. Float/double, mono/stereo, внутренняя арифметика double. Состояния старых версий мигрируют: Cancel → Punchy, удалённые стили → Clean, отсутствующий Knee → 0; Delta отбрасывается. Старые автоматизации по индексам после удаления Delta могут требовать переназначения.

## Сборка

JUCE 8.0.4, CMake ≥3.22, C++17, Xcode / Visual Studio 2022. По умолчанию **VST3 + AAX**, без Standalone/AU. JUCE содержит bundled AAX SDK; `AAX_SDK_PATH` нужен только для своего SDK.

```bash
cmake -S . -B build -DJUCE_DIR=/absolute/path/to/JUCE-8.0.4 -DCLIP_BUILD_UI_TESTS=ON
cmake --build build --config Release --parallel 2
ctest --test-dir build -C Release --output-on-failure
```

CI собирает Windows x64 и macOS Universal. AAX Developer-архивы требуют соответствующей PACE-подписи для обычного Pro Tools.

См. [DSP](Docs/DSP.md) и [Validation](Docs/VALIDATION.md). Старые бинарные файлы, изображения и логи в репозитории относятся к предыдущим версиям; текущие архивы доступны в Actions.
