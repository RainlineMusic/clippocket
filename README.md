# Clip Pocket 0.1.0

Новый JUCE-клиппер на базе интерфейса Duck Pocket. Это рабочая версия для прослушивания, разработки и дальнейшего сравнения с коммерческими клипперами. Хостовый float/double processing; внутри DSP использует double.

## Интерфейс

Две большие ручки **IN** и **Ceiling**, рядом **Output** и **Mix**. Ceiling по умолчанию **0.00 dB**. Три полосы показывают вход после IN, фактический выход и оценку gain reduction. Графиков формы волны нет.

Сохранены исходные PNG-материалы ручек, кольца свечения, фактура корпуса, Inter, темы **Solid Dark / Neon / Amber**; добавлена **Solid White**, меню, размер окна и blur при bypass. Дополнительные ручки можно свернуть. Двойной клик сбрасывает значение; правый клик открывает числовой ввод. Настройки интерфейса хранятся отдельно от Duck Pocket; идентификаторы и состояние нового плагина тоже отдельные.

## Начать слушать

1. Выбери **Clean**, **Master 8x**, IN 0 dB, Ceiling 0 dB, Output 0 dB.
2. Поднимай IN до необходимого срезания пиков. Для финального мастера попробуй **Ultra 16x**.
3. Включай **Delta**, чтобы слышать удалённую часть сигнала. Выключи его перед экспортом.
4. **Auto gain** компенсирует положительный IN для сравнения громкости. Это компенсация drive, не LUFS matching.
5. Попробуй Perceptual для спектрально управляемой мягкости и Punch для уменьшения этой мягкости на атаках.

## Модели

| Модель | Поведение |
|---|---|
| Clean | Дифференциальный oversampled clipper. Shape 0 — жёсткий срез; увеличение Shape расширяет плавное колено. |
| Perceptual | FFT используется только для анализа: тональность, высокочастотная энергия и атаки управляют коленом в oversampled DSP. Дополнительные Cleanliness, Focus и Punch активны здесь. |
| Soft | Более широкое колено: Shape отображается в диапазон фактической мягкости 50–100%. |

Perceptual — практическая спектральная эвристика. Это не сертифицированная психоакустическая модель и не оптимизация waveform по квадратичной программе.

## Все ручки

| Ручка | Диапазон | Назначение |
|---|---|---|
| IN | −24…+36 dB | Уровень до клиппера. |
| Ceiling | −30…0 dB | Порог и потолок сэмплов перед Output. |
| Output | −24…+12 dB | Финальный trim. Положительное значение поднимает итоговый потолок. |
| Mix | 0…100% | Параллельное смешивание до защитного guard. При Mix 0% guard продолжает ограничивать пики. |
| Shape | 0…100% | Непрерывное колено hard → soft. |
| Cleanliness | 0…100% | Сила спектрально управляемой мягкости в Perceptual. Это не регулятор качества FIR. |
| Focus | 0…100% | При больших значениях адаптивное колено ближе к жёсткому порогу. |
| Punch | 0…100% | Уменьшает адаптивную мягкость на обнаруженных атаках; не гарантирует сохранение любого транзиента. |
| Bass Anchor | 0…100% | Возвращает НЧ-часть удалённой коррекции через фильтр 180 Hz. Восстановленные пики снова контролирует guard. |
| Texture | −100…+100% | Меняет ВЧ-состав коррекции относительно фильтра 3.5 kHz. Отрицательные значения уменьшают ВЧ-коррекцию. |
| Stereo Link | 0…100% | От независимого среза каналов до общей мгновенной gain-кривой внутри oversampling. Защитный guard всегда связан по стерео. |
| Asymmetry | −100…+100% | Смещает соотношение положительного и отрицательного порога для чётных гармоник. |
| Phase Assist | 0…100% | Подмешивает первый порядок all-pass около 140 Hz. Меняет фазу и атаки; снижение пиков зависит от материала. |
| Release | 1…250 ms | Восстановление gain защитного guard; не время отпускания самого клиппера. |

В меню: **2x / 4x / 8x / 16x / 32x / 64x**, шесть заводских пресетов, сохранение/загрузка пользовательских `.clippreset`, автоматический **Maximum 64x на offline export**, DC correction, ISP Guard, tooltips и тема. На Windows сохраняется выбор native renderer; OpenGL доступен как экспериментальная опция на других платформах.

**DC correction** удаляет DC из создаваемой клиппером коррекции, а не из всего входного сигнала. **ISP Guard** оценивает межсэмпловые пики четырёхкратной windowed-sinc интерполяцией и использует запас 0.12 dB. Это не обещание строго заданного dBTP по любому реконструкционному фильтру. Delta и bypass — мониторинговые режимы, обычный ceiling для них не действует.

## Математическая основа

Основа — дифференциальная топология [US6337999B1, Robert Orban](https://patents.google.com/patent/US6337999B1/en): oversample входа, нелинейность, выделение удалённой части, FIR-фильтрация и вычитание коррекции из задержанного оригинала. Благодаря этому неактивный клиппер не пропускает исходный звук через resampling-фильтры.

Собственная реализация: каскад sparse halfband FIR, плавное квадратичное колено, стереосвязь на высокой частоте дискретизации, обработка спектра коррекции, FFT-управление коленом и финальный lookahead guard. Активные патенты B&O на perceptual optimization и автоматический поиск all-pass параметров не заявляются как реализованные алгоритмы. Подробности в [Docs/DSP.md](Docs/DSP.md).

Тестовые **Linux x64** VST3 и standalone включены в `Binaries/Linux-x64/`. Это сборка на Ubuntu 24.04; Windows и macOS бинарников в архиве нет. Исходники, инструкции и CI для них готовы.

При 48 kHz задержка **624 сэмпла / 13 ms**, одинакова для моделей, качества, Mix, Delta и bypass. Плагин сообщает её хосту. Формула: 512 + 64 + ceil(Fs × 0.001), guard ограничен 16…256 сэмплами. Это версия для обработки и мастеринга с компенсацией задержки, не zero-latency live effect.

## Сборка

Нужны CMake ≥3.22, C++17, JUCE **8.0.4**, Xcode на macOS или Visual Studio 2022 на Windows. JUCE не включён в архив. Его лицензию выбирает разработчик продукта.

```bash
cmake -S . -B build -DJUCE_DIR=/absolute/path/to/JUCE-8.0.4 -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel 2
ctest --test-dir build -C Release --output-on-failure
```

Артефакты: `build/ClipPocket_artefacts/Release/`. По умолчанию VST3 и Standalone. На macOS AU можно добавить через `-DCLIP_FORMATS="VST3;AU;Standalone"`. Для universal macOS: `-DCMAKE_OSX_ARCHITECTURES="arm64;x86_64" -DCMAKE_OSX_DEPLOYMENT_TARGET=11.0`.

Автоматический Maximum 64x включён по умолчанию и срабатывает, когда хост сообщает non-realtime rendering. Для рендера в реальном времени выбери 16x/32x/64x вручную. Его можно отключить в меню. Задержка при этом не меняется.

В `.github/workflows/build.yml` есть сборки Windows x64 и macOS universal с тестами и упаковкой. В этом архиве они ещё не запускались; CI запускается в твоём GitHub-репозитории. macOS CI использует ad-hoc подпись для разработки; релизная Developer ID подпись и notarization отдельно.

AAX поддержан конфигурацией CMake, но нужен лицензированный Avid SDK:

```bash
cmake -S . -B build-aax -DJUCE_DIR=/absolute/path/to/JUCE-8.0.4 -DAAX_SDK_PATH=/absolute/path/to/AAX_SDK -DCLIP_FORMATS="VST3;AAX"
cmake --build build-aax --config Release --parallel 2
```

AAX в этой среде не собирался. Для распространения в обычном Pro Tools также требуется соответствующая PACE-подпись. Наличие исходников AAX target не означает готовый подписанный AAX.

Чистые DSP-тесты без JUCE:

```bash
cmake -S . -B build-dsp -DCLIP_BUILD_PLUGIN=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build build-dsp --parallel 2
ctest --test-dir build-dsp --output-on-failure
```

UI-тесты: добавь `-DCLIP_BUILD_UI_TESTS=ON`; на Linux им нужен X11 display (`xvfb-run -a ctest ...`). Проверки и измерения описаны в [Docs/VALIDATION.md](Docs/VALIDATION.md). Исходные материалы Duck Pocket находятся в Assets; лицензионные уведомления шрифтов и backport JUCE сохранены.
