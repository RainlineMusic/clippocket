# Clip Pocket 0.6.0

Клиппер для Windows/macOS, VST3 + AAX. Только **Clean**, жёсткое ограничение. Большие Input и Output; между ними маленькие Ceiling и Low Protect, круглая кнопка Link и соединительные линии. Снизу горизонтальные сегментные OUT и GR, растущие слева направо. Подписи и сбрасываемые нажатием пиковые значения справа. Темы Solid Dark, Neon, Amber и bypass blur сохранены.

| Контрол | Работа |
|---|---|
| Input | −24…+36 dB перед клиппингом. |
| Output | −36…+24 dB после Ceiling; положительные пики разрешены. |
| Ceiling | −30…0 dBFS до Output. |
| Low Protect | 0…100%; защита формы НЧ-полуволн номинально до 100 Hz. |
| Link | По умолчанию выключен. При ручном редактировании Input/Output в редакторе устанавливает противоположный gain второй ручке. При включении выравнивает Output к −Input. |

Диапазон Output расширен до −36…+24 dB, чтобы Link поддерживал весь диапазон Input −24…+36 dB; сумма связанных gain равна нулю. Link не является автогейном по громкости; самостоятельная host automation обоих gain-параметров при закрытом редакторе остаётся самостоятельной. Для автоматизации обратного gain следует записывать оба параметра.

**GR** показывает оценку пикового ослабления клиппером и Low Protect до Output. Деление отдельного входного отсчёта на почти нулевой выход удалено. Тест входа 0 dBFS + Input 25 dB показывает 25 dB GR, в том числе при Output +12 dB. Это не LUFS/RMS-потеря громкости.

OUT: −30…+6 dBFS; GR: 0…36 dB. Пиковые значения не ограничены диапазоном шкалы. При Ceiling 0 и Output +1 выход достигает +1 dBFS. ISP/true-peak guard выключен.

Low Protect использует 30 ms lookahead плюс FIR-задержки: **2080 samples / 43.33 ms при 48 kHz**, одинаково при всех настройках. Восстановление старого состояния сохраняет общие параметры, удаляет Style/Knee, вводит Link выключенным. Внешние автоматизации по индексам удалённых параметров могут требовать переназначения.

Сборка: JUCE 8.0.4, CMake ≥3.22, C++17. По умолчанию VST3 + AAX, без Standalone/AU. CI создаёт четыре архива: macOS Universal и Windows x64, VST3 и AAX Developer. PACE-подпись для пользовательского Pro Tools поставляется отдельно.

```sh
cmake -S . -B build -DJUCE_DIR=/absolute/path/to/JUCE-8.0.4 -DCLIP_BUILD_UI_TESTS=ON
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Подробности и результаты проверок — Docs/DSP.md и Docs/VALIDATION.md.
